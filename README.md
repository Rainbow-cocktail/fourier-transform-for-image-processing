# 傅里叶变换两小时速成：图像工程版

面向只有高中数学基础、使用 Python 做图像处理的学习者。不要求预先掌握复数、欧拉公式或傅里叶积分。

课程遵循一个循环：**先看图 → 再运行 → 修改一个参数 → 用自己的话解释变化**。每个核心概念都配有 Matplotlib 图表，GitHub 页面也能直接显示已运行结果。

## 学习顺序

1. `00_从波到频谱_25分钟.ipynb`：从直角坐标换基底出发，理解弧度、正弦、相位、复数、正负频率和一维频谱（35 分钟）
2. `01_二维FFT看懂图像_30分钟.ipynb`：二维频谱、方向、幅度与相位（25 分钟）
3. `02_频域滤波与图像增强_35分钟.ipynb`：低通、高通、陷波、振铃（35 分钟）
4. `03_采样陷阱与实战模板_30分钟.ipynb`：混叠、泄漏和真实图片模板（25 分钟）

合计约 120 分钟。建议按顺序学习，每个代码单元使用 `Shift + Enter` 运行。

## 你会学到什么

- 从波形中找出隐藏的频率；
- 看懂二维图像频谱的中心、距离和方向；
- 使用低通、高通和陷波完成图像滤波；
- 避开混叠、频谱泄漏和硬截止振铃；
- 把课程代码替换成自己的图片。

## 安装与启动

在本目录打开终端：

```powershell
python -m pip install -r requirements.txt
python -m jupyter lab
```

如果使用 Anaconda，也可以从 Anaconda Navigator 启动 JupyterLab，再打开本目录。

浏览器打开后，从第 0 课开始。所有课程样例均为代码生成，不需要下载数据。

## 使用自己的图片

完成前三课后，在第 3 课中把 `image_path = Path("your_image.png")` 改成图片路径即可。

## 学习时只记住这四句话

1. 时域/空间域描述“每个位置是什么值”，频域描述“有哪些变化节奏”。
2. 频谱中心是慢变化，离中心越远变化越快。
3. 滤波就是给频谱乘一个掩膜。
4. 修改后通过逆傅里叶变换回到图像。
