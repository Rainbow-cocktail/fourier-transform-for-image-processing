01 为什么物镜会引入相位？

光的复振幅 E=A exp(iφ)。A 是振幅，φ 是相位。波前就是相位相同的点组成的曲面。平面波的波前是平面；理想会聚球面波的波前是以焦点为中心的球面。

理想物镜使来自同一个物点的光在焦点同相叠加。实际物镜的不同光路可能产生不同的光程误差。光程是折射率与传播距离的积分；实际光程相对理想参考波前的差值叫 OPD（Optical Path Difference），记为 W。

φ = 2πW / λ

为什么？传播一个波长， phase 增加 2π；传播 W，就增加 2πW/λ。以 λ=193 nm、W=10 nm 为例，φ=0.326 rad，P=exp(iφ)≈0.947+0.320i。模长仍是1，改变的是相位。这里采用正相位约定，其他软件可能采用负号。

PFRM 修正 Mask 出射场；Zernike 描述投影物镜的波前误差。两者不应混为同一种 Filter。

02 为什么要使用单位圆？

设物镜截止空间频率 fc=NA/λ（像方尺度）。将实际 pupil 频率 u,v 除以截止频率，得到归一化坐标 X=u/fc，Y=v/fc。

ρ = √(X²+Y²)， θ = atan2(Y,X)

ρ≤1 表示在圆形 pupil 内。比如 X=0.3，Y=0.4，则 ρ=0.5，θ≈53.13°。Zernike 就是在这个单位圆上定义的函数。注意：Abbe 中实际传入 pupil 的频率是 u=f+s，而不是单独的 mask 频率 f。

03 Zernike 为什么能表示复杂像差？

就像用多个正弦波组成复杂信号，我们可以用多个固定的二维函数组成波前误差。每个 Z 是一种形状，c 是该形状的权重。

W(ρ,θ) ≈ Σ ckZk(ρ,θ)

例如只考虑未归一化的 Defocus 和 X-Tilt：W=10(2ρ²−1)+5X，单位 nm。中心 W=−10；右边缘 W=15；左边缘 W=5。只用两个系数便定义了整个圆内的误差。

正交性意味着不同模式在单位圆上的乘积积分为零，因此可独立投影提取系数：ck=∫WZkdA / ∫Zk²dA（实值基函数）。极坐标面积元 dA=ρdρdθ。有限项展开只是近似。

模式未归一化公式典型影响
Piston1整体相位，不改变强度
Tilt X/YX / Y图像平移
Defocus2ρ²−1离焦
AstigmatismX²−Y² / 2XY方向相关焦点
Coma X/Y(3ρ²−2)X / (3ρ²−2)Y非对称 PSF
Spherical6ρ⁴−6ρ²+1不同孔径区域聚焦不一致

一般定义：Znm=Rn|m|(ρ) cos(mθ)（m≥0），负 m 使用 sin(|m|θ)。径向多项式为：

Rnq(ρ)= Σk=0…(n−q)/2 (−1)k(n−k)! ρn−2k / [k!((n+q)/2−k)!((n−q)/2−k)!]

n≥q，n−q 为偶数。例 n=2,q=0：k=0 得 2ρ²，k=1 得 −1，因此 R=2ρ²−1。工程中 Noll、Fringe、ANSI 的编号和归一化不同，不可直接混用。

05 从 Zernike 构造复数 Pupil

P(u,v)=A(u,v) exp[i 2πW(ρ,θ)/λ]

理想圆形孔径内 A=1，外 A=0。若 W=10(2ρ²−1) nm，λ=193 nm，那么中心 W=−10，ρ=1/√2 时 W=0，边缘 W=10。相位分别为 −0.326、0、+0.326 rad。注意系数若已经以 waves 表示，就只乘 2π；若以 radians 表示，不再乘 2π/λ。

Defocus 与 Zernike 的关系

均匀像方介质折射率 n，真空波长 λ，传播距离 z。角谱传播相位为 2πz√((n/λ)²−u²−v²)。扣除轴上公共相位：

φz= (2πnz/λ)[√(1−(NA/n)²ρ²)−1]

低 NA 近似 √(1−t)≈1−t/2，得到 φz≈−πz NA²ρ²/(nλ)。利用 ρ²=(Zdefocus+1)/2，忽略公共相位，未归一化 Defocus 的 OPD 系数为 −z NA²/(4n)。高 NA 时应使用准确传播相位，不要把已有离焦系数和额外传播项重复计入。

06 接回已经学过的成像公式

Abbe

Es(x)=∫ M(f;s)P(f+s) exp(i2πfx) df
I(x)=Σs Js|Es(x)|²

这里用一维简写，二维同理。厚掩膜 M(f;s) 来自 PFRM；薄掩膜 M(f) 与 s 无关。入射公共空间相位已略去，因为不影响强度。

Hopkins（薄掩膜）

TCC(f₁,f₂)=Σs JsA(f₁+s)A(f₂+s) exp{i[φ(f₁+s)−φ(f₂+s)]}

这个公式直接来自 P(f₁+s)P*(f₂+s)。假设一个光源，两个通过 pupil 的频率相位分别为0和π/2，则 TCC(1,2)=−i，TCC(2,1)=+i，两个对角元素均为1（J=1）。所以 TCC 是厄米矩阵，不必是实数。改变 Zernike 系数就改变了这些相位差，通常需要更新 TCC 和 SOCS 核。一般厚掩膜不能直接套用传统薄掩膜 TCC。

为什么 Tilt 会使图像平移？

若 W=cX，P 中的相位因子为 exp(i2πcu/(λfc))。根据傅里叶位移性质，乘线性相位使逆变换的场发生平移。在本讲义的正逆变换约定下，位移为 −c/(λfc)=−c/NA。Piston 则只是所有频率乘同一个相位，模平方后消失。

07 NumPy 实现：128×128 Pupil

import numpy as np
N = 128
lam = 193.0  # nm
NA = 0.85
dx = 10.0   # wafer-scale nm
f = np.fft.fftfreq(N, d=dx)
fx, fy = np.meshgrid(f, f)
X, Y = fx / (NA/lam), fy / (NA/lam)
r2 = X**2 + Y**2
A = (r2 <= 1).astype(float)
# coefficients in nm, unnormalized basis
W = 10*(2*r2-1) + 5*X
P = A * np.exp(2j*np.pi*W/lam)
h = np.fft.fftshift(np.fft.ifft2(P))
PSF = np.abs(h)**2
# coherent imaging, on-axis source
m = np.zeros((N,N))
m[:, 54:74] = 1
E = np.fft.ifft2(np.fft.fft2(m)*P)
I = np.abs(E)**2

这里使用未 shift 的 FFT 频率网格，与 fft2 输出一致。若加入斜入射，应在构造 X,Y 时使用 fx+sx、fy+sy；每个源分别计算光强再加权。实际 SMO 还需要检查不同 slit 的系数、偏振、NA、采样及归一化。以上代码为标量教学例，不代表实际高 NA 矢量模型。

08 自测与工程检查

1. W=λ/4 时 P 是多少？φ=π/2，孔径内 A=1 时 P=i。
2. 为什么 Piston 不改变强度？整个场乘 exp(iφ₀)，取模平方后该因子消失。
3. ρ=0.5 时未归一化 Defocus 基函数是多少？2×0.25−1=−0.5。
4. 改变 Zernike 系数，原来的 TCC 还能直接用吗？一般不能，因为频率间相位差改变。公共 Piston 是例外。
5. 系数为 0.02 waves，需要除以波长吗？不需要，直接乘 2π 得相位系数。

工程核查：系数单位、编号、归一化、坐标方向、相位符号、波长、NA、slit 位置、是否已包含 defocus。以上必须以实际模型文档为准。
